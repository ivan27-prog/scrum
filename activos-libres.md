# Activos Libres

## Recursos gratuitos para el proyecto

### 1. unDraw
Sitio con ilustraciones gratuitas que pueden utilizarse en proyectos web.

https://undraw.co/illustrations

### 2. Public Domain Vectors
Sitio con imágenes y vectores de dominio público.

https://publicdomainvectors.org/

## Uso en el proyecto

Estos recursos pueden utilizarse para agregar imágenes e ilustraciones al sitio web sin tener que crear todos los elementos gráficos desde cero.

Antes de utilizar cualquier recurso se debe revisar su licencia y condiciones de uso.
